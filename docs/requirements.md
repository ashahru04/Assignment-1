# Requirements

## Functional requirements (what the system must DO)
1. The system shall calculate the users body mass index (BMI) based on their weight and height that they have filled in.
2. The system shall recommend local meals that match with users BMI category.
3. The system shall allow user to view nutritional summary.
4. The system shall display calorie counts and nutritional breakdowns for recommended meals.
5. The system shall allow users to update their personal profile and target weight goals.

## Non-functional requirements (how the system must PERFORM)
1. The system shall calculate BMI results and load meal recommendations within 2 seconds.
2. The system interface shall be easy to understand for users to use it.
3. The system shall secure the users personal data and user health.
