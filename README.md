# Malaysian Diet Tracking System

A personalized diet tracking and food recommendation system tailored for Malaysians, analyzing user BMI to recommend healthy local meal choices and support weight normalization.

## Problem statement
Malaysians seeking to manage their weight frequently struggle because generic global diet plans fail to account for local dietary habits, making it difficult to translate their current Body Mass Index (BMI) into practical daily meal choices. Without personalized guidance tailored to local foods, individuals are left guessing how to adjust their nutrition to safely return to a normal BMI range.
